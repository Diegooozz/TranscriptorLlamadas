# 🐾 Tole Tole · Transcriptor de Llamadas

Transcribe en vivo (español / inglés) tu micrófono y el audio de la PC usando Whisper de forma local,
con traducción inglés → español sin internet. Guarda todo en `Documentos/Transcripciones`.

## Uso
```
pip install -r requirements.txt
python transcriptor.py
```
O ejecuta `iniciar.bat`. Con `crear_acceso.ps1` creas un acceso directo en el Escritorio con el icono de Tole Tole.

> Usa audífonos para evitar que se duplique el audio. Graba conversaciones solo con el consentimiento
> de los participantes, según la ley de tu país.
